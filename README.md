# Project-One
Dilution calculator for lab work
## Daily Goal: 
Spend 2 hours a day learning/implementing Java using this project.
## Features:
- **Dilution mode selection:** able to switch between different calculation types.
- **Input validation:** prevent crashes from invalid user entries.
- **Simple Dilution Calculator:** able to calculate a single dilution.
- **Input validation** prevent incorrect data from being entered e.g. 0.00 ml for Volume.
